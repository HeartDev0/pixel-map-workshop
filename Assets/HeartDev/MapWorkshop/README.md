# Pixel Map Workshop

Source-available Unity tool by HeartDev. Open **Tools → HeartDev → Pixel Map Workshop**.

The tool permits commercial use with attribution under **LICENSE.txt**. Redistribution,
resale, sublicensing and transfer of the tool/source are restricted. Included props,
example maps and screenshots are **evaluation-only**, not usable in projects;
see **LICENSE-EXAMPLES.txt** and `Examples/Restricted/LICENSE.txt`.

Current guide: https://github.com/HeartDev0/pixel-map-workshop

Paint terrain, patterns and layers; place native-scale sprite props; select groups,
rotate in X, create seed-based bases, water zones, bridges and ambient effects, then
save your document and export/update a prefab. Authoring stays in an Editor-only assembly.
Requires Unity 6000.6 and URP 17.6 with a Universal 3D renderer.
